# Shared quadratic mesh

Holds `net_pullout_alt_coarse_quad.inp`, the quadratic C3D10M mesh
(298,586 elements, 480,770 nodes) used by the Abaqus reference run.
Needed by `make_paper_figure_phase_grid_alpha_variants.py` to map node
labels to strand identity when drawing the Fig. 8 panels.

See `../quadratic_C3D10M_alpha1000/README.md` for the reference run.
