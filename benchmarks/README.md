# Benchmarks

One folder per benchmark in the paper. Each contains the simulation
script(s), a `postprocessing/` or `figures/` folder with the
figure-generating scripts, and a `NOTES.md` describing what each script
does and which figure/table it produces.

| folder | paper section | produces |
|---|---|---|
| `three-pts_bend_test/` | Sec. 3 | Fig. 2, Fig. 5, Table 1 |
| `two_orthogonal_beams/` (incl. `friction/`) | Sec. 4 | Fig. 6, Fig. 7, App. B.5 |
| `net_pullout/` (incl. `abaqus/`) | Sec. 5 | Fig. 8, Fig. 9 |
| `computational_cost/` | Sec. 4.5 | Table 2 |
| `toy_cases_appendix/` | App. A | Table A1 and Appendix A figures |
